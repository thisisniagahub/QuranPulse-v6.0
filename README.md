## 🌟 Project Overview
QuranPulse v6.0 is a **Progressive Web App (PWA)** designed to revolutionize the Islamic digital experience. It moves beyond static PDF reading to an immersive, AI-powered ecosystem.

### Key Features
* **🧠 Smart Deen (AI Companion):** "Ustaz AI" powered by Hybrid Engine (Groq/Gemini). *Currently in Mock Mode for UI dev.*
* **📖 Iqra Digital:** Educational module with 3D interactions, Voice Coach (ASR Prototype), and Vision Coach.
* **🕌 Ibadah Suite:** Next-gen Prayer Times with "Meteocons", Qibla Finder, and Mosque Locator.
* **💎 Nabdh Design System:** A premium "Electric Cyan & Deep Navy" aesthetic with glassmorphism and motion.

## 🛠️ Technology Stack (Powered By)
We use a cutting-edge stack to ensure performance and scalability:
* **Core:** React 18, Vite, TypeScript
* **Styling:** Tailwind CSS v4, Framer Motion
* **Icons:** Solar Icons (Vectors), Iconify
* **Backend:** Supabase (Postgres, Edge Functions, Auth)
* **AI:** Google Gemini 2.0 Flash, Groq, OpenAI Whisper (ASR)
* **Deployment:** Vercel
