# Artifacts

`artifacts/` stores generated or working-output material that should not clutter the repository root.

## Sections

- `audio/`: extracted or generated audio outputs
- `downloads/`: downloaded working assets
- `generated/`: generated media or one-off output folders
- `logs/`: manual logs and experiment traces
- `playwright-report/`: Playwright HTML report output
- `test-results/`: Playwright test result output

Generated content may be regenerated by tooling, so this folder is intentionally separated from source and documentation.
