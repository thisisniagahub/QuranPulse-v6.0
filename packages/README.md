# Packages

`packages/` contains reusable internal content bundles, source packs, and domain datasets.

## Current Packages

- `iqra-content/`: JSON content used by the main app at runtime
- `iqra-hub/`: master Iqra source documents and PDFs
- `reference-content/`: long-form PDF references and extracted text
- `umrah-content/`: Umrah reference bundle and raw source files

These are treated as internal repository packages even when they are content-first rather than code-first.
