# Page Template for Iqra-1 Guides

## Usage Instructions
Use this template to create new Iqra-1 pages by replacing the placeholders with specific content.

```markdown
# Panduan Bimbingan Iqra 1 - Muka Surat {PAGE_NUMBER}
## {LESSON_TITLE}

---

### Diagram Aliran Bacaan (Kanan ke Kiri)
Dalam setiap kotak, anda perlu mula membaca dari arah anak panah ini:
```
[ 3 ] <--- [ 2 ] <--- [ 1 ]
```

### Diagram Struktur Kotak (Baris demi Baris)

| Baris | Kotak Kanan (Mula Sini) | Kotak Kiri (Seterusnya) | Fokus Latihan |
| :--- | :--- | :--- | :--- |
| TAJUK | {TITLE_RIGHT} | {TITLE_LEFT} | Perbezaan bentuk {PRIMARY_LETTER} & {SECONDARY_LETTER}. |
{EXERCISE_ROWS}

### Diagram Perbandingan Karakter (Identiti Huruf)
```mermaid
graph LR
A[Huruf {PRIMARY_ARABIC} - {PRIMARY_LETTER}] --> A1(Bentuk: {PRIMARY_SHAPE})
A --> A2(Bunyi: {PRIMARY_SOUND}!)
A --> A3(Sifat: {PRIMARY_TRAIT})
B[Huruf {SECONDARY_ARABIC} - {SECONDARY_LETTER}] --> B1(Bentuk: {SECONDARY_SHAPE})
B --> B2(Bunyi: {SECONDARY_SOUND}!)
B --> B3(Sifat: {SECONDARY_TRAIT})
```

### Diagram "Checklist" Kelancaran
Untuk menganggap diri anda sudah "paham" dan "lulus" muka surat ini, anda perlu pastikan:

- [ ] **Arah Benar:** Mata bergerak dari kanan ke kiri tanpa tertukar.
- [ ] **Bunyi Pendek:** Tidak membaca Aaaaa (2 harakat), tapi {PRIMARY_SOUND}! (1 harakat).
- [ ] **Kenal Titik:** Pantas bezakan {PRIMARY_LETTER} ({PRIMARY_SHAPE}) dengan {SECONDARY_LETTER} ({SECONDARY_SHAPE}).
- [ ] **Kelajuan Tetap:** Boleh baca Baris Akhir tanpa berhenti atau berfikir lama.

### Ringkasan Untuk Anda
Bayangkan imej ini sebagai satu set latihan "Gym" untuk mata. Baris atas adalah *warm-up*, dan baris paling bawah adalah *heavy lifting*. Jika anda sudah boleh sebut baris terakhir **"{FINAL_EXERCISE}"** dengan sekali nafas dan kelajuan yang stabil, bermakna saraf otak anda sudah berjaya menterjemah kod visual Arab tersebut dengan sempurna!

---
*Generated by QuranPulse AI Engine*
```

## Placeholders Guide

| Placeholder | Description | Example |
|-------------|-------------|---------|
| `{PAGE_NUMBER}` | Page number | `1` |
| `{LESSON_TITLE}` | Lesson title | `Pengenalan Huruf Alif dan Ba'` |
| `{PRIMARY_LETTER}` | Main letter name | `ALIF` |
| `{SECONDARY_LETTER}` | Secondary letter name | `BA` |
| `{PRIMARY_ARABIC}` | Arabic letter | `أ` |
| `{SECONDARY_ARABIC}` | Arabic letter | `ب` |
| `{PRIMARY_SHAPE}` | Letter shape description | `Tiang Tegak` |
| `{SECONDARY_SHAPE}` | Letter shape description | `Mangkuk (Titik Bawah)` |
| `{PRIMARY_SOUND}` | Letter sound | `A` |
| `{SECONDARY_SOUND}` | Letter sound | `BA` |
| `{PRIMARY_TRAIT}` | Letter characteristic | `Jelas & Tajam` |
| `{SECONDARY_TRAIT}` | Letter characteristic | `Bibir Rapat` |
| `{TITLE_RIGHT}` | Right box title content | `أَ` |
| `{TITLE_LEFT}` | Left box title content | `بَ` |
| `{EXERCISE_ROWS}` | All exercise rows (excluding header) | See format below |
| `{FINAL_EXERCISE}` | Final exercise text | `أَ بَ أَ   بَ أَ بَ` |

## Exercise Row Format
```markdown
| Baris {ROW_NUM} | {RIGHT_CONTENT} | {LEFT_CONTENT} | {EXERCISE_TYPE} |
```

Where `{EXERCISE_TYPE}` is typically:
- `Latihan tukar bunyi secara berselang-seli.`
- `Ujian Akhir: Kelancaran sebelum pindah MS.`
