# 📖 Iqra Digital — Scope & Overview

> **Last Updated**: 21 Feb 2026
> **Status**: Active
> **Module**: Iqra Digital

---

## 1. Included Scope (In-Scope)
We are building a **Progressive Web Application (PWA)** module that teaches the "Iqra" method (Books 1-6) using Voice Recognition.

### Content
* **Iqra 1:** Individual Letters (Hijaiyah) & Basic Sounds (Fathah).
* **Iqra 2:** Joining letters (Sambung) & Mad Asli (2 harakat).
* **Iqra 3:** Kasrah (i), Dhommah (u), Sukun (dead letters).
* **Iqra 4:** Tanween (an, in, un) & Qalqalah.
* **Iqra 5:** Waqaf (Stopping) signs & Tashdid (Double letters).
* **Iqra 6:** Advanced rulings (Idgham, Iqlab, Ikhfa) & Quranic Script nuances.

### Tech Capabilities
* **Real-time ASR:** Listen to user saying "Ba" and valid "Correct/Wrong".
* **Visual Feedback:** Green highlight for correct, Red shake for incorrect.
* **Gamification:** Stars/Progress per page to unlock the next level.

## 2. Excluded Scope (Out-of-Scope via MVP)
* **Complex Tajweed Analysis:** No Makhraj diagrams (tongue placement visualizations) for MVP.
* **Tafsir:** Meaning is not relevant at this stage; focus is pure decoding (reading).
* **Multi-User classrooms:** We build for single-player (1 device = 1 user focus) initially.

## 3. Success Criteria
* **Accuracy:** MVP accepts "close enough" pronunciation (80% confidence).
* **Latency:** Feedback must appear under 1.5 seconds.
* **Retention:** 50% of users who start Iqra 1 finish Page 5.
