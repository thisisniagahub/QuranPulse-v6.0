## 3. Unique Functionalities in `quran-agent`

These are the "Gems" found in `quran-agent` that `QuranPulse` currently lacks:

### 💎 A. The Q-WER Metric (Quran Weighted Error Rate)
Instead of standard Word Error Rate (WER), it implements a theological weighting system:
*   **Makhraj Error:** 3.0x penalty (Critical).
*   **Tajweed Error:** 2.5x penalty.
*   **Vowel Error:** 2.0x penalty.
*   *Code Location:* `main.py` (Logic implemented in `analyze_audio` endpoint).

### 💎 B. Robust Audio Preprocessing
It doesn't just feed raw audio to AI. It "cleans" the signal first, crucial for Malaysian environments (fans, echo).
*   **Stationary Noise Reduction:** Uses `noisereduce` to strip background hiss.
*   **LUFS Normalization:** Uses `pyloudnorm` to ensure consistent volume (-23 LUFS).
*   *Benefit:* Drastically improves AI accuracy on cheap microphones.

### 💎 C. "Adab" Logic (Isti'adzah Trimming)
It intelligently detects "A'udhu billah..." at the start of audio and trims it so the AI focuses only on the Quranic verse comparison.
*   *Code Location:* `preprocessing/arabic_utils.py`
