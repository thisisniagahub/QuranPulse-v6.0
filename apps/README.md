# Apps

`apps/` contains standalone application workspaces that are separate from the main root Vite app.

## Current Workspaces

- `admin-dashboard/`: Next.js admin and moderation interface
- `niagahub-superapp/`: secondary product workspace and exploratory superapp code

The main QuranPulse web app remains at the repository root for now to avoid a high-risk `apps/web` migration in the same refactor.
