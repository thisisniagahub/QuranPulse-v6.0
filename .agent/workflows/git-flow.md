# /git-flow — Git Operations Pipeline 🌿

// turbo-all

Structured git workflow with conventional commits and automated PRs.

## Prerequisites
- Git repo initialized
- GitHub remote configured

## Workflow Steps

### Step 1: Assess Current State
```bash
git status
git branch --show-current
git log --oneline -5
```

### Step 2: Branch Strategy
If on `main`/`master` and making feature changes:
```bash
git checkout -b <type>/<short-description>
```

Branch naming convention:
```
feat/add-auth          — New feature
fix/cors-headers       — Bug fix
refactor/extract-utils — Code refactoring
docs/update-readme     — Documentation
chore/update-deps      — Maintenance
hotfix/critical-bug    — Emergency fix
```

### Step 3: Stage Changes
```bash
git add -A
git diff --cached --stat    # Show what's staged
```

### Step 4: Commit with Convention
Generate commit message automatically:

```
<type>(<scope>): <description>

[optional body — what changed and why]

[optional footer — breaking changes, issue refs]
```

Types: `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`, `perf`, `ci`

```bash
git commit -m "<auto-generated message>"
```

### Step 5: Push
```bash
git push -u origin <branch>
```

### Step 6: Create Pull Request
Via GitHub MCP:
```
mcp_github_create_pull_request:
  owner: <from git remote>
  repo: <from git remote>
  title: <type>(<scope>): <description>
  head: <feature-branch>
  base: main
  body: |
    ## Changes
    - <list of changes>
    
    ## Testing
    - <how it was tested>
```

### Step 7: Report
Report to user:
- Branch: `feat/add-auth`
- Commit: `feat(auth): add JWT authentication`
- PR: #42 — [link]

## Quick Commands
```
/git-flow commit    → Steps 3-4 only (stage + commit)
/git-flow push      → Steps 3-5 (stage + commit + push)
/git-flow pr        → Full pipeline (branch + commit + push + PR)
```
