# /ship — Ship It Pipeline 🚢

// turbo-all

Build → Test → Git → Deploy → Verify. One command to rule them all.

## Prerequisites
- Code changes are ready to ship
- Git repository initialized

## Workflow Steps

### Step 1: Pre-flight Check
```bash
npm run build 2>&1         # Must pass
npx tsc --noEmit 2>&1      # Must pass
npm run lint 2>&1           # Should pass (auto-fix if possible)
```

If ANY check fails:
- Auto-fix if possible (lint, formatting)
- If build/type error → fix code → re-run
- NEVER ship broken code

### Step 2: Git Stage & Commit
```bash
git add -A
git status
```

Generate conventional commit message based on changes:
```
feat: add user authentication with JWT
fix: resolve CORS issue on API routes
docs: update README with deployment guide
refactor: extract shared utils to lib/
chore: update dependencies
style: improve landing page responsiveness
```

Format: `<type>(<scope>): <description>`

```bash
git commit -m "<generated message>"
```

### Step 3: Push to Remote
```bash
git push origin <current-branch>
```

If push fails (behind remote):
```bash
git pull --rebase origin <branch>
git push origin <branch>
```

### Step 4: Create PR (if feature branch)
If NOT on `main`/`master`, create PR via GitHub MCP:
```
mcp_github_create_pull_request:
  title: <conventional title>
  body: <auto-generated description with changes list>
  head: <current-branch>
  base: main
```

### Step 5: Deploy
Detect deployment target from project:
```
vercel.json exists     → vercel deploy (auto via git push)
Dockerfile exists      → docker build + push
netlify.toml exists    → netlify deploy
fly.toml exists        → fly deploy
```

For Vercel (default):
- Push triggers auto-deploy
- Wait for deployment URL
- Verify via Puppeteer MCP screenshot

### Step 6: Post-Ship Verification
```
mcp_puppeteer_puppeteer_navigate → deployment URL
mcp_puppeteer_puppeteer_screenshot → capture result
```

Report to user:
- ✅ Build passed
- ✅ Deployed to: [URL]
- 📸 Screenshot attached

## Example Trigger
```
User: "ship it" / "deploy" / "/ship"
Agent: [build] → [commit: feat: add dashboard] → [push] → [deployed ✅]
```
