# Project Handover Workflow

// turbo-all

## Steps

### 1. Check for PROJECT_MEMORY.md

Look in the current workspace root for `PROJECT_MEMORY.md` or `.agent/context.md`

### 2. If found, read the memory file

Read `PROJECT_MEMORY.md` to understand:

- Project overview and status
- Current task progress
- Critical rules and constraints
- User preferences

### 3. Check TASK.md for current work

Read `TASK.md` if it exists to see:

- What was completed
- What is in progress
- What is pending

### 4. Confirm understanding

Briefly confirm: "Saya dah baca PROJECT_MEMORY - [project]. Status: [status]. Ready!"

### 5. Continue work

Proceed with user's request using full context
